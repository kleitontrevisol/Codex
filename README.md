# Galeria Livre

Protótipo de galeria Android local, sem conta e sem envio de fotos à nuvem. **Versão inicial experimental:** lista fotos, álbuns e vídeos, permite favoritar durante a sessão e abrir/compartilhar mídia. Editor, pasta criptografada, lixeira e detecção de duplicatas ainda não foram implementados.

O APK de depuração será gerado em Actions > Gerar APK Android > Artifacts, após uma compilação bem-sucedida. Não é necessário publicar na Google Play.
